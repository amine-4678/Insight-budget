# Insight-budget
A modern personal finance web application for budgeting, expense tracking, savings goals, and financial analytics.

---

##  Dashboard Preview

![Dashboard Preview](imgs/dashboard-preview.png)

---

##  Project Status

**Currently in Development**

Insight Budget is a personal finance web application that helps users manage their money, track expenses, create budgets, and achieve savings goals through a modern and intuitive dashboard.

---

##  Planned Features

-  Interactive Dashboard
-  Wallet Management
-  Expense Tracking
-  Budget Planning
-  Savings Goals
-  Financial Analytics
-  Transaction History
-  Smart Notifications
-  Dark / Light Mode
-  User Authentication
